# Top K Frequent Elements

**Topic:** Arrays & Hashing · **Difficulty:** Medium

## Summary

Given an array of integers and a number `k`, return the `k` values that occur
most often, in any order. The inputs guarantee that these `k` values are
uniquely determined.
